# FC2ライブ コメント連携プラグイン for わんコメ

[わんコメ（OneComme）](https://onecomme.com/) に、[FC2ライブ](https://live.fc2.com/) の公式コメントAPIを利用してコメントを取り込むプラグインです。

通常コメントだけでなく、**匿名コメントの個別識別（通し番号付与）**、**ギフト・チップの通知**、**配信者コメントの識別**、**NG処理**に完全対応しています。  
わんコメ公式推奨設計に準拠した**専用のWeb設定画面（UI）**を内蔵しており、ブラウザから簡単にチャンネルIDやトークンを設定できます。

---

## 主な機能

- **専用Web設定画面（公式推奨設計）**: わんコメのプラグイン画面からワンクリックで設定UIを開き、ブラウザ上で簡単に設定可能。
- **枠一覧の自動セレクト**: わんコメ側の枠一覧を自動取得してドロップダウンから選択可能（手動でのID入力は不要）。
- **リアルタイム接続ステータス表示**: 接続中、正常稼働、認証エラー（Token切れや未配信）を画面上で一目で把握。
- **公式コメントAPI連携**: 安定した公式エンドポイントを利用してリアルタイムにコメントを取得。
- **匿名コメントの個別識別**: FC2の匿名コメント（hash）を解析し、「匿名(1)」「匿名(2)」のように識別表示。
- **ギフト・チップ対応**: 風船やハートなどの各種ギフト演出、チップ金額をコメントとしてわかりやすく表示。
- **NGコメント処理**: NGキーワードやNGユーザーのコメントを安全にマスキング。
- **ゼロ外部依存（Pure Node.js）**: 外部npmパッケージを含まず、わんコメ本体を安定して動作させます。

## 導入手順

### 1. ダウンロードと配置
1. 本リポジトリ右上の **「Code」→「Download ZIP」**（または Releases）からZIPファイルをダウンロードし、解凍します。
2. わんコメを開き、左上の **メニュー「≡」→「連携」→「プラグイン」** を開きます。
3. プラグイン一覧画面の **「フォルダを開く」** ボタンをクリックします。
   （エクスプローラーで `%APPDATA%\onecomme\plugins` が開きます）
4. 解凍したフォルダ（フォルダ名を `fc2-live` 等にリネーム推奨）をプラグインフォルダ内に配置します。

フォルダ構成のイメージ:
```text
plugins/
  fc2-live/
    plugin.js
    index.html
    config.sample.json
    README.md
    LICENSE
```

### 2. わんコメ側で枠を追加
1. わんコメの左側「視聴者」または「配信」一覧の **「＋」** ボタンを押して新規枠を作成します。
2. 枠の名前を **`#FC2`**（または `FC2`）にするか、URLに自分のFC2ライブ配信URL（例: `https://live.fc2.com/12345678/`）を入力して保存します。

### 3. 簡単Web設定画面から設定
1. わんコメの **「プラグイン」** 一覧画面を開き、**「FC2ライブ コメント連携」** の項目にある **「設定」ボタン（歯車アイコンまたはURL）** をクリックします。
   （ブラウザで `http://localhost:11180/plugins/com.fc2live.comment-sync/index.html` が開きます）
2. 画面の指示に従って以下を入力します：
   - **FC2 チャンネルID**: 自分の配信ページURLの数字部分
   - **FC2 コメントAPIトークン**: FC2の[プロフィール編集ページ](https://live.fc2.com/profile_edit/)の「コメントAPIの設定」で発行されるアクセストークン
   - **わんコメ連携先枠**: プルダウンから選択（「✨ 自動検出」のままでOK）
3. **「設定を保存して接続」** をクリックすると、即座に接続が開始されます！

※従来通り `config.json` をテキストエディタで直接編集して設定することも可能です。
