# FC2ライブ コメント連携プラグイン for わんコメ

[わんコメ（OneComme）](https://onecomme.com/) に、[FC2ライブ](https://live.fc2.com/) の公式コメントAPIを利用してコメントを取り込むプラグインです。

通常コメントだけでなく、**匿名コメントの個別識別（通し番号付与）**、**ギフト・チップの通知**、**配信者コメントの識別**、**NG処理**に完全対応しています。

---

## 主な機能

- **公式コメントAPI連携**: 安定した公式エンドポイントを利用してリアルタイムにコメントを取得。
- **匿名コメントの個別識別**: FC2の匿名コメント（hash）を解析し、「匿名(1)」「匿名(2)」のように識別表示。
- **ギフト・チップ対応**: 風船やハートなどの各種ギフト演出、チップ金額をコメントとしてわかりやすく表示。
- **配信枠の自動検出**: わんコメ側の枠一覧から「FC2」または「live.fc2.com」を含む枠を自動で検索して紐付けます（面倒なUUIDの入力は不要です）。
- **NGコメント処理**: NGキーワードやNGユーザーのコメントを安全にマスキング。

## 導入手順

### 1. ダウンロードと配置
1. 本リポジトリ右上の **「Code」→「Download ZIP」**（または Releases）からZIPファイルをダウンロードし、解凍します。
2. わんコメを開き、左上の **メニュー「≡」→「連携」→「プラグイン」** を開きます。
3. プラグイン一覧画面の **「フォルダを開く」** ボタンをクリックします。
   （エクスプローラーで `%APPDATA%\onecomme\plugins` が開きます）
4. 解凍したフォルダ（フォルダ名を `fc2-live` 等にリネーム推奨）をプラグインフォルダ内に配置します。

フォルダ構成のイメージ:
```text
plugins/
  fc2-live/
    plugin.js
    config.sample.json
    README.md
    LICENSE
```

### 2. わんコメ側で枠を追加
1. わんコメの左側「視聴者」または「配信」一覧の **「＋」** ボタンを押して新規枠を作成します。
2. 枠の名前を **`#FC2`**（または `FC2`）にするか、URLに自分のFC2ライブ配信URL（例: `https://live.fc2.com/12345678/`）を入力して保存します。
   （※プラグインがこの名前・URLを自動検知してコメントを流し込みます）

### 3. APIキー・チャンネルIDの設定
1. プラグインフォルダ内の `config.sample.json` をコピーして **`config.json`** にリネームします。
   （初回起動時に自動生成される `config.json` をそのまま編集しても構いません）
2. テキストエディタ（メモ帳やVSCode等）で `config.json` を開きます。
3. FC2のチャンネルIDとコメントAPIトークンを入力します。

```json
{
  "channel_id": "あなたのFC2チャンネルID（数字）",
  "token": "FC2コメントAPIトークン",
  "serviceId": "",
  "intervalMs": 2500
}
```

#### 各項目の確認方法:
- **`channel_id`**: 自分の配信ページURL（例: `https://live.fc2.com/12345678/`）の末尾の数字です。
- **`token`**:
  1. [FC2ライブ プロフィール編集ページ](https://live.fc2.com/profile_edit/) にアクセス（要ログイン）
  2. ページ中ほどにある「**コメントAPIの設定**」セクションを確認
  3. 表示されている「**アクセストークン**」の文字列をコピーして貼り付けてください。

### 4. 有効化
わんコメのプラグイン画面で **「再読み込み」** を押すか、わんコメを再起動すると自動で接続が開始されます。

---

## 設定項目一覧 (`config.json`)

| キー | 型 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| `channel_id` | 文字列 | 必須 | FC2ライブのチャンネルID（数字） |
| `token` | 文字列 | 必須 | FC2ライブのコメントAPIアクセストークン |
| `serviceId` | 文字列 | `""` | わんコメの枠ID。**空欄のままでOK**（枠名やURLから自動検出されます） |
| `intervalMs` | 数値 | `2500` | コメント取得間隔（ミリ秒）。推奨2500（2.5秒） |
